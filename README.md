# CSS 布局实验室

《元素类型、溢出与浮动》互动课堂页面，内容依据第六组 PPT 精简重排。

## 课堂入口

- HTTPS：<https://yimengdao.github.io/css-float-classroom/>
- 阿里云备用：<http://120.26.127.91/zhaoxin/css-float/>

## 使用

- `←` / `→`、`PageUp` / `PageDown`：切换章节
- `Home` / `End`：跳到首尾
- `F`：切换全屏
- 页面包含 display、overflow、浮动塌陷和文字省略的实时互动实验
- 核心术语旁附“通俗版 / 换个说法”，方便课堂口头解释
- 仅依赖一个 `index.html`，无构建步骤、无 CDN 依赖

## 部署

- GitHub Pages：`main` 分支根目录
- 阿里云 ECS：`/usr/share/nginx/html/zhaoxin/css-float/index.html`
